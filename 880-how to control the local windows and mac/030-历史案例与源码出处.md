## 五、复用时要改什么

十月脚本为<伙伴A>机专用：机器名 `<目标机主机名>`；初版还绑定目标 IP。它只检查已经运行的 `sshd`，不负责新装服务或分发公钥。

其 `.cmd` 读取自身嵌入的 PowerShell 载荷，必要时弹出 UAC，再添加访问规则和到期清理任务。新电脑需要按现有状态决定安装与配置，不能直接双击这份脚本照搬。

九月脚本 `w` 注释中保留过 `http://<局域网IP>:8765/w` 的服务地址；这是另一阶段的现场暂存地址，不能当成 Air 十月下载地址。

后续通用工具应把机器识别、目标用户、公钥、允许来源、有效期和回滚记录参数化；首先在新的 Windows、Mac 上分别完成一次真实接入验收。

## 六、已经踩过的坑

- Windows 管理员公钥路径与普通账户不同，ACL 不正确会导致认证失败；中文系统应避免依赖英文组名。
- Windows SSH 在 session 0，GUI 安装和原生程序在这里失败，不一定代表用户桌面也失败。
- 多行 PowerShell 经标准输入可能出现解析问题，优先上传后 `-File` 执行。
- PowerShell 5.1 编码需要明确，不能随意把含中文脚本作为无 BOM UTF-8 运行。
- Windows 截图需考虑 DPI 缩放；点击任务与目标窗口权限不匹配时可能静默无效。
- 用户同时操作桌面时，截图后的坐标可能已失效，不能连续盲点。
- 临时放行与长期保留是不同的最终状态，要查看当次收尾记录。
