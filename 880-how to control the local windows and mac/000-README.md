> 局域网 Windows / Mac 接入与维护入口。2026-11-05 已验证 Windows 管理员级 SSH 接入，以及 MacBook Air M1 的公钥接入、软件部署、Ghostty 启动 OpenCode 和桌面会话切换微信输入法。各项功能验收边界见案例；通用多机工具仍需参数化。

## 一、目标与默认策略

每台 Windows 首次接入时，用户只运行一条短命令并确认管理员授权。AI 准备官方来源或自有已检查脚本、接收机器信息、完成真实连接验收，再继续部署。长期授权不设置到期时间，临时下载入口按时关闭。

默认采用管理员级 SSH + PowerShell 和文件传输，不安装远程桌面。需要验证软件窗口时，可另用当前用户交互式计划任务启动并截图；这个能力必须独立验收，不能从 SSH 成功直接推定。

本项目中的「控制」指 Windows / Mac 正常运行时，经授权的命令、文件与系统管理能力。Mac 的管理员权限、隐私权限和桌面会话分别验证。账号登录、系统启动前解锁、故障停机不因 SSH 接入而自动解决。
